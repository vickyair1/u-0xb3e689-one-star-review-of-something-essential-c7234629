## The line

> Gravity: excellent attendance, zero sick days, and it has never once helped carry anything upstairs.

100 characters. Written as a deadpan performance review filed in earnest: gravity never misses a day, never calls in sick — and still refuses to do the one thing anyone would actually want from it. The sting lands in the last few words, on the stairs everyone has cursed it on.
